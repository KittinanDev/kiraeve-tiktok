ใส่ไฟล์วิดีโอ/เสียงของคุณในโฟลเดอร์นี้ ชื่อไฟล์ต้องตรงกับที่ตั้งไว้ใน config.json

ตัวอย่างไฟล์ที่ต้องมี (ตามตัวอย่างใน config.json ที่ให้มา):
  background_loop.mp4   -> ฉากพื้นหลังที่วนลูปตลอดเวลา (แทนกรีนสกรีน)
  thanks.mp3            -> เสียงขอบคุณเวลามีคนส่งกุหลาบ
  wave.mp4              -> คลิปโบกมือ
  dance.mp4             -> คลิปเต้น
  special_thanks.mp4    -> คลิปพิเศษสำหรับของขวัญราคาแพง
  default_reaction.mp4  -> คลิปสำรอง เผื่อของขวัญที่ไม่ได้ตั้งค่าไว้

จะลบ/เพิ่ม/เปลี่ยนชื่อไฟล์และของขวัญที่ผูกกันได้อิสระ แค่แก้ config.json ให้ตรงกัน
ระวังเรื่องลิขสิทธิ์เพลง/คลิปที่นำมาใช้เล่นสดด้วย

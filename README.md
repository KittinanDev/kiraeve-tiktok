# NPC Live Overlay — ฟังของขวัญจาก TikTok LIVE แล้วเล่นคลิป/เพลง + กรีนสกรีน

ระบบนี้มี 3 ส่วน รันด้วยเซิร์ฟเวอร์ตัวเดียว (`server.py`):

1. **`server.py`** — เว็บเซิร์ฟเวอร์ (aiohttp) ที่เชื่อมต่อ TikTok LIVE ของบัญชีคุณแบบ "ฟังเฉย ๆ"
   ดักจับ event ของขวัญแบบเรียลไทม์ พร้อมเปิดหน้า dashboard และ overlay ให้ในตัว
2. **`dashboard.html`** — หน้าจัดการ: เพิ่ม/แก้ไข/ลบของขวัญที่ผูกกับคลิป, กด "ทดสอบ" แล้วดูตัวอย่าง
   ที่จะขึ้นในสตรีมได้ทันทีในหน้าเดียวกัน
3. **`overlay.html`** — หน้าที่เอาไปใส่เป็น **Browser Source ใน OBS** แสดงฉากพื้นหลัง (แทนกรีนสกรีน)
   วนลูปตลอด และเล่นคลิปวิดีโอ/เสียงเมื่อมีของขวัญเข้ามา (หน้าเดียวกับที่ preview ใน dashboard ใช้)

ใช้ไลบรารี [`TikTokLive`](https://github.com/isaackogan/TikTokLive) (unofficial, reverse-engineered) — ไม่ต้อง login ไม่ต้องขอ API key
แต่ก็เพราะไม่เป็นทางการ **TikTok อาจเปลี่ยนระบบแล้วทำให้หลุดชั่วคราวได้ทุกเมื่อ** จนกว่าไลบรารีจะอัปเดตตาม

---

## 1) ติดตั้ง

ต้องมี Python 3.9 ขึ้นไป

```bash
cd npc-live-overlay
pip install -r requirements.txt
```

## 2) ใส่ไฟล์วิดีโอ/เพลง

เอาไฟล์คลิป/เสียงของคุณไปวางในโฟลเดอร์ `media/` (ดูรายละเอียดใน `media/README.txt`)
ต้องมีลิขสิทธิ์/สิทธิ์ใช้งานคลิปหรือเพลงที่เอามาเล่นสดด้วย

## 3) รันเซิร์ฟเวอร์

```bash
python server.py
```

จะเห็น log ว่า `เปิดเซิร์ฟเวอร์ที่ http://localhost:8765/` แปลว่าพร้อมแล้ว

### 🖥️ การรันและบิลด์เป็นแอปพลิเคชันเดสก์ท็อป (Desktop App / .exe)

#### 1. การรันในโหมดพัฒนา (Development Mode)
เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วรัน:
```bash
npm start
```
ระบบจะเปิดหน้าต่างแอป **TikTok LIVE Interactive Studio** ให้อัตโนมัติ พร้อมสั่งรัน Python Backend ในเบื้องหลัง

#### 2. การสร้างตัวติดตั้งแอปพลิเคชัน (.exe Installer / Portable)
เพื่อบิลด์โปรเจกต์เป็นไฟล์ติดตั้ง `.exe` สำหรับ Windows ให้รันคำสั่ง:
```bash
npm run dist
```
เมื่อบิลด์เสร็จ ไฟล์ติดตั้งและโปรแกรมพร้อมรันจะถูกสร้างไว้ในโฟลเดอร์ **`dist/`**
- `dist/NPC Live Overlay Setup 1.0.0.exe` (ตัวติดตั้ง Installer)
- `dist/win-unpacked/NPC Live Overlay.exe` (โปรแกรมแบบพร้อมรัน Portable)

## 4) เปิดหน้าจัดการ (Dashboard)

เปิดเบราว์เซอร์ไปที่ **http://localhost:8765/**

- ใส่ **username TikTok** ของบัญชีที่จะไลฟ์ (ไม่ต้องมี `@`)
- เพิ่มแถวของขวัญ: ชื่อของขวัญ (ต้องตรงกับชื่อจริงใน TikTok เช่น `Rose`, `GG`, `Lucky 9`), เลือกประเภทวิดีโอ/เสียง,
  ใส่ path ไฟล์ (อ้างอิงจาก `media/` เช่น `media/dance.mp4`) และระยะเวลาที่จะให้เล่น
- ใส่แถวชื่อ **`_default`** ไว้เป็นคลิปสำรอง เผื่อของขวัญที่ไม่ได้ตั้งค่า
- กด **บันทึกการตั้งค่า**
- กด **ทดสอบ** ที่แถวไหนก็ได้ → คลิปจะเล่นให้ดูทันทีในกล่อง "ตัวอย่างที่จะขึ้นในสตรีม" ทางขวา
  (กล่อง preview นี้กับ overlay จริงใน OBS รับสัญญาณจากเซิร์ฟเวอร์ตัวเดียวกัน ดังนั้นสิ่งที่เห็นใน preview
  คือสิ่งที่จะขึ้นจริงในสตรีมเป๊ะ ๆ)
- สถานะมุมขวาบนจะบอกว่าตอนนี้เชื่อมต่อไลฟ์อยู่หรือไม่ (ต้องกำลังไลฟ์อยู่จริงถึงจะขึ้น "เชื่อมต่อไลฟ์แล้ว")

> ชื่อของขวัญจริงเช็คได้จากที่คนอื่นเคยได้รับ หรือดู log ของ `server.py` ตอนมีคนส่งของขวัญเข้ามาจริง

## 5) ตั้งค่า OBS (ทำให้เป็นกรีนสกรีนจริง)

0. ตั้ง Canvas ของ OBS เป็นแนวตั้งก่อน (เมนู **Settings → Video → Base/Output Resolution** → ใส่ **1080x1920**)
   เพราะไลฟ์ TikTok เป็นแนวตั้ง
1. เพิ่ม **Browser Source** ใหม่ → ใส่ URL **`http://localhost:8765/overlay.html`** (ไม่ใช่ Local File แล้ว
   เพราะตอนนี้ server.py เสิร์ฟหน้านี้เอง ต้องรัน `python server.py` ทิ้งไว้ตลอดเวลาที่ไลฟ์)
   → ตั้ง **Width 1080, Height 1920** (overlay.html เป็นหน้าที่ยืดเต็มขนาดของ Browser Source เองอัตโนมัติ
   ไม่ต้องแก้โค้ด แค่ใส่ตัวเลขให้ตรง) → ติ๊ก "Resize output (source) to match window" ไม่จำเป็นเพราะ Browser Source
   ปรับตามค่า Width/Height ที่ตั้งอยู่แล้ว
2. เพิ่ม **Video Capture Device** (กล้อง/เว็บแคม) เป็นเลเยอร์ **อยู่เหนือ** Browser Source
3. คลิกขวาที่กล้อง → Filters → เพิ่ม **Chroma Key** → เลือกสีคีย์ (เขียว) — ต้องมีฉากเขียวจริงด้านหลังคนถ่าย แสงสม่ำเสมอ ไม่มีเงา
4. จัดเลเยอร์: **บนสุด = กล้อง (มี Chroma Key)**, **ล่าง = Browser Source (overlay.html)**
   ผลลัพธ์: พื้นหลังจริงถูกลบออก เห็นฉาก+คลิปจาก overlay.html แทน เหมือนในคลิปตัวอย่างที่ส่งมา

## 6) ไลฟ์เข้า TikTok

ต้อง live ผ่าน **TikTok LIVE Studio** (โปรแกรมบนคอม) ไม่ใช่แอปมือถือ เพราะแอปมือถือไม่รองรับ overlay จากภายนอก
ตั้งค่า OBS ให้ stream ออกเป็น RTMP ไปที่ TikTok LIVE Studio ตามขั้นตอนปกติของการตั้งค่า OBS + TikTok

## ข้อควรระวัง

- `TikTokLive` เป็นไลบรารี unofficial — ถ้า TikTok เปลี่ยนโปรโตคอล อาจต้องรอ/อัปเดตไลบรารีก่อนถึงจะใช้ได้ใหม่
- ต้องมีสิทธิ์ LIVE บน TikTok (ผู้ติดตามถึงเกณฑ์ที่แพลตฟอร์มกำหนด) และต้องมีสิทธิ์ใช้เพลง/คลิปที่เอามาเล่นระหว่างไลฟ์
- ต้องรัน `python server.py` ทิ้งไว้ตลอดเวลาที่ต้องการให้ dashboard และ overlay ใช้งานได้ (ปิดสคริปต์ = overlay ใน OBS ก็เล่นคลิปไม่ได้ด้วย)
- ถ้าอยากได้ความเสถียรระดับ production มีบริการ API แบบมี webhook/SLA ให้ใช้แทน เช่น Euler Stream, tik.tools, Tikfinity
